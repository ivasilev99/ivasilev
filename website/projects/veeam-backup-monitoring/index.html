Veeam backup monitoring

I built monitoring for the Veeam backup server and every job on it, so we always knew whether last night's backups succeeded, were still running, or failed.

Where
Radioactive EOOD
Role
System Administrator
Stack
  • Veeam Backup & Replication
  • Zabbix
  • Windows Server

The problem

Backups were only checked when someone remembered to open the Veeam console. A failed or stuck job could go unnoticed until the day a restore was needed.

How I did it

  1. Monitored the Veeam backup server itself, so we knew it was up and its services were running.
  2. Tracked every backup job and its last result: success, warning or failed.
  3. Flagged jobs that were still running long after they should have finished.
  4. Added triggers per state, so a failed or stuck job raises an alert instead of waiting to be found.

Result

Backup health became visible at a glance, and a failed job turned into an alert the same day instead of a surprise during a restore.
